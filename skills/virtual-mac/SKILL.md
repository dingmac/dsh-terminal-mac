# 虚拟 Mac（terminal-mac）

一台**独立于用户真实桌面的 macOS 虚拟机**。它有自己的账号、桌面、应用与文件系统；宿主与它只共享一个控制邮箱和一份只读工具目录。用户鼠标、剪贴板、摄像头、主目录一概不共享。

## 一、自己判断要不要用（不要问用户"要不要开虚拟 Mac"）

**直接使用**，满足任一条即是：
- 需要 GUI：打开/安装应用、点菜单、拖窗口、用没有命令行的工具（设计稿、Finder 整理、系统设置、截图看界面）
- 需要在隔离环境里跑可疑或破坏性的桌面操作
- 需要"看界面才知道下一步"的任务（布局判断、状态确认）

**不要用**：
- 纯命令、文件、代码任务 → 用 bash / 文件工具
- 纯网页任务 → 用浏览器工具，虚拟机反而慢
- 只是"想有个干净环境"但没有 GUI 需求 → 不值得付 4 GB 内存

## 二、成本与自动关机（这是硬要求）

- **运行中**：固定占约 **4 GB 内存** + 最多 2 核 CPU；宿主 swap 紧张时会明显拖慢用户机器
- **停止后**：只占磁盘（约 29 GB），内存与 CPU 归零
- **因此：任务一结束就关掉，不要留给下一轮**。用户没明确说"保持开着"，就自己关。

判断顺序：
1. 本任务还有后续桌面步骤吗？有 → 留着
2. 客户机里有**未保存的文档/编辑中的内容**吗？（截图看窗口标题的圆点、是否停在编辑界面）
   - 有 → 先保存（cmd+s），再关
   - 有且存不了 → 用普通 `stop`，让用户在客户机里点一次「关机」确认
3. 都没有 → `terminal_mac_vm_stop { force: true }`，几秒完成

> 一次对话里反复开关是可以的：启动约 30–60 秒，且客户机是**免密自动登录**，不需要用户输密码。

## 三、标准流程：观察 → 操作 → 验证

1. `terminal_mac_vm_status` → 若不是 `running`，`terminal_mac_vm_start`（等它到 running）
2. `mcp__terminal-mac__screenshot` → 看当前画面。**在登录界面或权限弹窗就报告用户，不要瞎点**
3. 用**最新一张截图**的像素坐标操作：
   - `mcp__terminal-mac__click { x, y }`（双击 `clicks: 2`，右键 `button: "right"`）
   - `mcp__terminal-mac__type { text }`（字面文本，走 Unicode 输入，不碰剪贴板）
   - `mcp__terminal-mac__key { key: "cmd+space" }`（组合键、return、tab、escape、方向键）
   - `mcp__terminal-mac__drag` / `scroll` / `move`
4. 每个有意义的动作都加 `screenshot: true`，或紧接着再截一张，**确认结果再说下一步**
5. 任务完成后按第二节关机

## 四、审批：由你按任务决定，不是全局开关

三个改状态的工具（start / stop / pause）都有可选参数 `confirm`：

| 场景 | 做法 |
|---|---|
| 普通任务（开个应用、点几下） | 不带 `confirm`，直接执行 |
| 可能丢数据 / 影响用户的事（客户机里有没保存的文档要断电、批量删除、跨会话共享的机器） | 带 `confirm: true`，走审批卡 |
| 会话策略是「从不询问」 | **不要带 `confirm`**：`ask` 会被确定性拒绝，调用直接失败（fail closed）。改为直接执行，并在回复里说明风险 |
| 会话策略是「询问」而你没带 `confirm` | 直接执行，不弹卡 —— 这正是"两种都支持"的含义 |

策略当前值可以从运行时上下文里读到；读不到时先不带 `confirm` 试一次。

## 五、工具清单

**操作客户机**（MCP，命名空间 `mcp__terminal-mac__`）：
`screenshot` `click` `move` `drag` `scroll` `type` `key` `status`

**管理虚拟机**（本插件原生）：
`terminal_mac_vm_status` / `terminal_mac_vm_start` / `terminal_mac_vm_stop` / `terminal_mac_vm_pause` / `terminal_mac_vm_resume`

## 六、坐标与输入规则

- 坐标是**最新截图的像素**，左上角原点；这台机器是 1280×800 点、2 倍缩放，截图像素与输入坐标一一对应
- 动作之后画面会变，旧坐标立即失效 —— 每次操作前用最新截图
- `type` 输入中文没问题；要调出 Spotlight 用 `key: cmd+space`，要关窗用 `key: cmd+w`
- 截图是 JPEG，模型看到的就是坐标系本身

## 七、出错怎么办

| 返回 | 原因 | 处理 |
|---|---|---|
| `VM 'default' is stopped` | 已关机 | `terminal_mac_vm_start` |
| `No virtual Mac named ...` | 从没建过 | 告诉用户需要先 `terminal-mac up`（要下载 macOS、需人工设置） |
| `no logged-in session` | 停在登录界面或 helper 未运行 | 报告用户；不要重试点击 |
| 权限 `false` | 屏幕录制/辅助功能授权失效 | 告诉用户在客户机里重新授权 |
| `command timed out`（关机） | 客户机弹了关机确认框 | 确认无未保存内容后改 `stop { force: true }` |

## 八、禁忌

- **不要**用宿主的截屏、点击、剪贴板工具做兜底 —— 那会抢用户焦点、动用户真实数据
- **不要**在客户机里登录用户的真实账号或放敏感凭据；客户机默认能上网，这不是网络隔离环境
- **不要**把 `force` 当默认：它等同拔电源
- **不要**为了画面好看去改分辨率/缩放 —— 坐标系会变
- **不要**留虚拟机常开当"下次方便" —— 用户机器只有 16 GB 内存
